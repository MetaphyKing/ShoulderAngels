# Changelog

All notable changes to ShoulderAngels are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/); versioning is
[SemVer](https://semver.org/).

## [1.1.0] — 2026-09-06

Pluggable completion backends so the tool can run without Anthropic. Schema
validation, choose/forecast orchestration, and history stay in this package;
the host LLM (Grok Bot, a subagent, or any script) only supplies `complete`.

### Added
- Explicit `Completer` Protocol (`complete(prompt, system="") -> str`).
- `CallableClient` — wrap any `(prompt, system) -> text` callable.
- `CommandClient` — spawn an external command: JSON
  `{"prompt","system"}` on stdin; stdout is JSON `{"text":...}` or raw text.
  Timeout and non-zero/empty output raise `LLMError`.
- CLI `--backend {anthropic,command}` (default `anthropic`) and
  `--complete-cmd CMD`. Env: `SHOULDERANGELS_BACKEND`,
  `SHOULDERANGELS_COMPLETE_CMD`. Command backend does **not** need
  `ANTHROPIC_API_KEY`.
- `AnthropicClient` alias for `LLMClient` (import name unchanged).
- Public `ShoulderAngels.record(result)` to append a finished decision
  without re-running propose.
- `examples/fake_completer.py` for offline `--backend command` runs.
- Offline tests for CallableClient, CommandClient, and the command CLI path.

### Changed
- `ShoulderAngels(..., client=...)` is typed as `Completer`, not only
  `LLMClient`.
- Version `1.1.0`.

## [1.0.0] — 2026-06-24

First production-quality release. Hardened from the NICHE autogenerated scaffold
into a tested, packaged, shippable tool.

### Added
- `LLMClient`: dependency-free Anthropic client with timeout, exponential
  backoff retries on 408/429/5xx, lazy API-key resolution, and clear `LLMError`
  messages.
- `extract_json()`: defensive parser for JSON embedded in model output
  (raw, ```json fences, or prose-wrapped).
- `--choose {safe,bold,both}` for non-interactive / pipeline use.
- `--model`, `--max-tokens`, `--no-store`, `--history`, `--version` flags.
- Decision history persistence (`~/.shoulderangels/history.json`) — the
  previously-dead `store` is now a real append-only ledger.
- Target coercion: accepts a plain string, a JSON/dict, or a file path.
- `pyproject.toml` with a `shoulderangels` console entry point.
- 22 offline tests (LLM mocked), `EXAMPLES.md`, `CHEAT_SHEET.txt`,
  `INTEGRATION_PLAN.md`, MIT `LICENSE`, `.gitignore`.

### Fixed
- **Crash**: scaffold called `target.get('agents')` on a CLI string — removed
  the type mismatch; `run()` now coerces input robustly.
- **Deadlock in pipelines**: blocking `input()` collided with `--json`; the
  interactive prompt now triggers only on a real TTY with no forced choice.
- Missing `ANTHROPIC_API_KEY` produced a raw `KeyError`; now a helpful message.
- Fragile JSON fallback that string-sliced the response is replaced by
  validated normalization with sane defaults.
- Redundant in-function `import json` removed.

### Changed
- Single live API call retained as the core mechanism (per Organism protocol),
  but all unit tests run offline against a fake client.
